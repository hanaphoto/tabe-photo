たべフォト｜説明書

食事処の撮影（業務）も、旅先の食の記録も。カメラ付きチェックリストアプリの使い方

1. このアプリについて

「たべフォト」は、アプリの中でカメラ撮影まで完結し、何を撮ったかが項目リストで分かるスマホ向けアプリです。飲食店を撮る仕事にも、旅行先で食べたものを記録する使い方にも対応するため、案件ごとに2つのモードがあります。

モード向いている使い方特徴
業務モード（紺テーマ）飲食店の撮影仕事、メニュー・店舗写真の納品必須／推奨／任意の優先度、目標枚数、写真の採用・不採用の選別、撮影終了チェック、納品向けファイル名のZIP書き出し
旅記録モード（暖色テーマ）旅行・外食の思い出記録料理名・価格・星評価・再訪したいか・感想を記録し、文章化した「日記テキスト」を書き出せる
  • ログイン不要、インターネット不要（オフラインで動きます）
  • 入力したデータと写真はこの端末の中だけに保存され、外部へ送信されることはありません
  • 位置情報は使いません。場所は住所などのテキストで記録します

アプリを開く

2. 始め方（iPhone）

  1. Safariで https://hanaphoto.github.io/tabe-photo/ を開く
  2. 共有ボタン（□に↑）→「ホーム画面に追加」を選ぶ
  3. ホーム画面の「たべフォト」アイコンから開く（次からはオフラインでも開けます）
  4. 最初にカメラを使う時、カメラの許可を求められます。「許可」を選んでください

Androidの場合は Chrome のメニューから「ホーム画面に追加」／「アプリをインストール」です。

大切な注意：データと写真は、ホーム画面に追加したアプリ（またはSafari）の保存領域（IndexedDB）に入ります。Safariの「履歴とWebサイトデータを消去」をするとデータも写真も消えます。大事な撮影の後は、必ず§7のZIP書き出しでバックアップを取ってください。

3. 業務モードの流れ

  1. 案件一覧で「＋ 業務撮影の案件」を押す
  2. 店名・日付・場所を入れて保存する。外観／店内／料理／メニュー／人物・その他の定番項目が自動で入ります
  3. 項目を現場に合わせて追加・編集・削除し、↑↓で並べ替える。各項目に優先度（必須／推奨／任意）と目標枚数を付ける
  4. 項目一覧で「カメラで撮る」を押して撮影する。撮った写真は自動でその項目に付き、項目は「撮影済み」になります
  5. 写真をタップすると大きく見られます。その場で「採用／お気に入り／不採用／未確認」の印を付ける
  6. 終わったら「撮影終了チェック」で、必須の未撮影・撮り直し・未確認写真の残りを確認し、ZIPで書き出す

項目の状態（5段階）

状態意味
未撮影まだ撮っていない
撮影済み写真が1枚以上ある（カメラ撮影・取り込みで自動的になります）
確認OK写真を見て、使えることを確認した
撮り直しもう一度撮る必要がある
対象外今回は撮らないと決めた

項目一覧の状態バッジを押すと、この順番で切り替わります。フィルターは「すべて／未撮影／撮り直し」です。

最初に入る項目（業務テンプレート）

カテゴリ主な項目
外観店舗正面（看板含む）、入口・看板ロゴ、斜め前からの外観
店内店内全景（入口側）、店内全景（奥側）、カウンター席、テーブル席、個室・座敷、内装・装飾
料理看板料理、おすすめ料理、定食・セット全体、料理アップ（寄り）、ドリンク、デザート、季節限定
メニューメニュー表紙、メニュー各ページ、価格表・案内
人物・その他店主・スタッフ、調理風景、SNS用縦構図、横構図（バナー用余白）

4. 旅記録モードの流れ

  1. 案件一覧で「＋ 旅記録を追加」を押す
  2. 店名・日付・場所のほか、旅行名・食事区分（朝／昼／夕／間食）・同行者（選択式）を入れる
  3. 項目は「お店」「食事」「思い出」のシンプルなセットが入ります（必須はありません）。項目ごとに料理名と価格を記録できます
  4. 食べたら写真を撮り、星評価（1〜5）・再訪（ぜひ／迷う／なし）・感想を付ける
  5. 「日記を見る」で、記録が文章化された日記テキストを表示。コピーや.txt ダウンロード、ZIP書き出し（日記.txt入り）ができます

日記には、旅行名／店名／日付／食事区分／食べたもの／合計金額（価格の自動合計）／評価／再訪／感想が入ります。ブログやSNSの下書きにもそのまま使えます。

5. カメラと写真の保存

  • カメラ画面では、現在の項目名・カテゴリ・撮影枚数（目標枚数つき）が表示されます
  • グリッド表示の切り替え、前後カメラの切り替え、大きなシャッター、直近に撮った写真のサムネイル表示があります
  • 連続して撮れるので、同じ項目で何枚も撮影できます。「次の未撮影へ」で項目を移動できます
  • 撮影した写真は、保存が成功してから初めて項目が「撮影済み」になります（保存に失敗した写真が「撮ったこと」にはなりません）
  • カメラが使えない環境（許可しない場合など）では、項目ごとの「写真を取り込む」から写真アプリの写真を取り込めます。これも同じく「撮影済み」になります

写真ビューア

サムネイルをタップすると写真を大きく表示します。前後の写真への移動、採用／お気に入り／不採用／未確認の切り替え、1枚だけのダウンロード、削除ができます。

6. 画質についての注意（大切）

  • このアプリのカメラは、ブラウザの仕組み（Webカメラ）で撮影します。写真の長辺は最大1920px、JPEG画質0.92で保存します
  • iPhone標準カメラアプリのような高画質・高画素ではありません。記録用・Web掲載用・確認用には十分ですが、大きく印刷する納品写真などは一眼カメラや標準カメラアプリで撮ってください
  • 撮影情報（EXIF：撮影日時・レンズ情報・GPSなど）は基本的に残りません。アプリ内には撮影日時が記録されますが、書き出したJPEG自体にEXIFが入ることは期待しないでください
  • ズームや細かい露出調整はブラウザ側の仕様に依存します。対応していない端末では使えません

7. 書き出しとバックアップ

形式中身用途
ZIP書き出し（写真込み）写真を 01_採用・お気に入り／02_未確認／03_不採用 にフォルダ分け＋撮影一覧.csv＋記録.json（旅記録は日記.txtも）バックアップと納品の本命。ファイル名は YYYYMMDD_項目連番_項目名_枚番.jpg
CSV書き出し区分・項目・状態・目標・写真枚数・採用枚数・料理名・価格・メモ・最終撮影日時記録用。Excelやスプレッドシート、Notionへの取り込みに
JSON書き出し／読み込み案件情報と項目だけ（写真は含まれません）項目リストの使い回し、端末間の案件移行に。読み込むと既存の案件を消さずに追加されます
日記.txt（旅記録）文章化した食の記録ブログ・SNS・日記の下書きに

共有シートが使える端末では、ZIP書き出しで共有シートが開きます（ファイルアプリやAirDropへ送れます）。使えない場合はダウンロードになります。

バックアップ推奨：写真は端末の中にしかありません。撮影が終わったら、その日のうちにZIP書き出しをして、パソコンやクラウドへ移してください。JSONだけでは写真は戻りません。

8. 撮影終了チェック（業務モード）

必須項目の未撮影件数、撮り直しの件数、未確認（印が付いていない）写真の枚数が表示され、残りがあれば警告が出ます。あわせて次の4項目を確認します。

  1. 必須カット完了
  2. 写真を確認した
  3. 店名表記を確認した
  4. 書き出し（ZIP）を済ませた

残りがあるまま案件を完了にしようとすると、確認画面が出ます。

9. 案件の複製

同じお店の再撮影や、同じ旅行パターンの記録では、案件一覧の「複製」が便利です。項目リストやメモは引き継がれ、状態はすべて「未撮影」に戻ります。写真は複製されません。

10. データとプライバシー

  • データと写真の保存先は端末内の IndexedDB だけです。サーバー送信、アクセス解析、広告は一切ありません
  • 位置情報は取得しません。カメラの映像も端末の中で処理され、外部へ送られません
  • アプリのコード自体に個人情報は含まれていません。公開されているのは「空のアプリ」だけです
  • 店名や住所をどこまで入れるかは運用次第です。端末のパスコードがそのまま守りになります
  • 機種変更の前には、案件ごとにZIP書き出しをしてください（JSONでは写真が移りません）

11. よくある質問・困った時

カメラが起動しない

カメラの許可が必要です。Safariの設定でこのサイトのカメラ許可を確認するか、ホーム画面アプリを一度開き直してください。それでも使えない場合は、標準カメラで撮ってから「写真を取り込む」で取り込めます。

データや写真が消えた

Safariのデータを消去した、プライベートブラウズで使っていた、別のブラウザで開いた、などが原因として考えられます。ZIPバックアップがあれば写真は戻せますが、アプリ内への自動復元はできません（ZIPは保管・納品用です）。

オフラインで使える？

使えます。一度オンラインで開けば、本体が端末に保存され、圏外でも撮影・記録ができます。

iPhone Safariで入力欄を押すと画面が拡大する

入力欄の文字サイズを16pxにして防いでいます。もし拡大する場合は、ピンチで戻してください。

写真が保存できない

端末の空き容量不足の可能性があります。不要な写真を削除するか、ZIPで書き出してからアプリ内の案件を削除してください。
