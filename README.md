# たべフォト（tabe-photo）

食事処（飲食店）で静止画を撮るための、カメラ付きチェックリストPWA。
アプリの中で撮影まで完了し、「何を撮ったか」が項目リストで管理できます。
業務の店舗撮影にも、旅先の食の記録にも使えるよう、案件ごとにモードを切り替えます。

- アプリ名：たべフォト（ホーム画面名も同じ）
- リポジトリ：hanaphoto/tabe-photo
- 公開URL：https://hanaphoto.github.io/tabe-photo/
- 説明書：https://hanaphoto.github.io/tabe-photo/manual.html （アプリの案件一覧にある「説明書」ボタンからも開ける）
- 仕様書：`~/workspace/food-photo-camera/SPEC.md`（v1.0確定、ChatGPT相談を検証・取捨して確定）

## モード
- **業務モード（紺テーマ）**：飲食店の撮影仕事向け。項目の優先度（必須／推奨／任意）、目標枚数、写真の採用／お気に入り／不採用の選別、撮影終了チェック（必須の未撮影・撮り直し・未確認写真の警告）
- **旅記録モード（テラコッタの暖色テーマ）**：旅行・外食の記録向け。料理名・価格・星評価（1〜5）・再訪（ぜひ／迷う／なし）・同行者（選択式）・食事区分（朝／昼／夕／間食）を記録し、文章化した日記テキストを書き出せる

## 使い方（要点）
1. 案件を作る（業務／旅記録を選ぶ）と、モード別のテンプレート項目が入る。追加・削除・並べ替え（↑↓）で整える
2. 項目の「カメラで撮る」でアプリ内撮影（getUserMedia → canvas → JPEG）。写真が保存できたら初めて項目が「撮影済み」になる。カメラが使えない時は「写真を取り込む」でも同じ扱いになる
3. サムネイルから写真ビューアを開き、採用／お気に入り／不採用／未確認の印を付ける。項目の状態は 未撮影／撮影済み／確認OK／撮り直し／対象外 の5段階
4. 終わったらZIP書き出し（写真は採用・未確認・不採用にフォルダ分け、撮影一覧.csv・記録.json同梱、旅記録は日記.txtも）。CSV／JSON単体書き出し、JSON読み込み（写真は復元されない旨を画面に明記）、案件の複製にも対応

## ファイル
- `index.html` 本体（フレームワーク・外部ライブラリ無し。案件と写真は IndexedDB `tabephoto-v1` に保存。ZIP書き出しは store 方式・無圧縮・CRC32 の自前実装で、外部ライブラリを使わない）
- `manual.html` 説明書ページ
- `manifest.webmanifest` / `sw.js`（キャッシュ名 tabephoto-v1）
- `icon-180.png` / `icon-192.png` / `icon-512.png` / `icon-maskable-512.png`
  - デザイン：テラコッタ地に白い皿＋フォーク、琥珀色のチェック円バッジ。`make_icons.py` で再生成可

## 公開時の注意
- 公開対象は `index.html / manual.html / manifest.webmanifest / sw.js / icon-*.png / README.md` のみ
- `make_icons.py`（アイコン生成用・内部パスを含む）と、書き出したZIP／JSON／CSVバックアップはリポジトリに入れない
- アプリのコードに個人情報は含まれない。利用時に入力した店名・メモと撮影写真は端末の IndexedDB にだけ保存され、外部送信の仕組みは無い
- 画質の注意：Webカメラ撮影のため長辺最大1920px・JPEG 0.92 で、EXIFは基本的に残らない。標準カメラアプリのような高画質ではない（説明書 §6 に明記）
